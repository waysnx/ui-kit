## ⭐ What this package does

Data editing and viewing components — JSON editor, XML viewer, code editor/viewer, and markdown editor/viewer with syntax highlighting, line numbers, and live preview.

---

## Package info

- **npm:** `@waysnx/ui-data` v1.0.1 (companion package — NOT in `@waysnx/ui-kit` meta)
- **Install:** `npm install @waysnx/ui-data`
- **Peer deps:** `react >=18`, `react-dom >=18`
- **CSS (required):** `import '@waysnx/ui-data/dist/index.css'`

---

## Exported components

| Component | Purpose |
|-----------|---------|
| `JSONEditor` | JSON editing with validation |
| `XMLViewer` | XML display with syntax highlighting |
| `CodeViewer` | Read-only code display with syntax highlighting |
| `CodeEditor` | Editable code with syntax highlighting |
| `MarkdownEditor` | Markdown editing with toolbar |
| `MarkdownViewer` | Rendered markdown display |
